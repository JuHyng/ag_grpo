# Notices

This repository contains the implementation for AG-GRPO by Juhyeong Kim, Gyunyeop Kim, and Sangwoo Kang.

The training code builds on ideas and APIs from:

- Hugging Face Transformers and TRL.
- Open-R1-style SFT/GRPO utilities included under `open_r1/`.
- LLaDA-style masked diffusion language model generation, especially block-wise denoising.

Files derived from upstream projects retain their original license headers where present.
