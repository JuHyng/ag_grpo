# Public Release Checklist

Use this checklist before pushing a tagged public release.

- [ ] README command examples run from a fresh clone.
- [ ] `configs/` match the paper hyperparameters.
- [ ] No local checkpoints, W&B logs, pycache files, or datasets are tracked.
- [ ] Dataset download/preparation steps are documented.
- [ ] Code-execution rewards clearly warn about sandbox requirements.
- [ ] License and citation files are present.
- [ ] Third-party code attribution is documented in `NOTICE.md`.
- [ ] A small smoke test or compile check passes.
- [ ] Full evaluation scripts are added or clearly marked as pending.
